# 32 — Neon Drive: общий лидерборд

В этой версии кнопка с кубком находится под музыкой в главном меню. Имя предлагается после заезда, если результат попал в общий топ-10. Пока таблица не заполнена, подходит любой положительный результат. Равный последнему месту результат не вытесняет его. Перед сохранением место проверяется снова.

Каждый заезд сохраняется отдельной записью. Один телефон можно передавать разным людям. Имена могут повторяться — даже все десять строк могут принадлежать одному имени. Повторная отправка одного заезда не создает дубликат. Имя — до 10 символов; последнее введенное имя подставляется из localStorage, но его можно изменить. Старые записи таблицы сохраняются. Авторизации нет. В таблице отображаются только имя и метры. Это простая таблица для вечеринки с базовой проверкой правдоподобности дистанции, а не полноценная защита от читов.

## Как включить на Netlify

Обычная загрузка ZIP через Netlify Drop публикует статические файлы, но не собирает серверную функцию. Для этой версии нужен деплой из Git или через Netlify CLI.

### Вариант через GitHub

1. Распакуй архив. Создай репозиторий GitHub и загрузи в его корень содержимое архива: dist, netlify, server, tests, package.json, package-lock.json, netlify.toml. Папку node_modules загружать не нужно.
2. В существующем проекте Netlify открой Project configuration → Build & deploy → Continuous deployment и подключи репозиторий (Link repository). Так адрес сайта останется прежним.
3. Base directory оставь пустой. Настройки уже указаны в netlify.toml: Build command — npm test, Publish directory — dist, Functions directory — netlify/functions. Node.js — 22.
4. Запусти production deploy и дождись успешного завершения. Netlify установит зависимости и соберет функцию.
5. Открой сайт, нажми кубок: должна появиться пустая таблица вместо ошибки подключения. Заверши заезд, введи имя и проверь запись с другого телефона.

Сервер использует Netlify Blobs. В штатном деплое Netlify Functions доступ к нему настраивается платформой; отдельные ключи или сторонняя база не нужны. Таблица привязана к проекту Netlify и сохраняется при следующих деплоях. Новому проекту будет соответствовать отдельная таблица.

### Вариант через командную строку

Установи Node.js 22 или новее. В распакованной папке:

```sh
npm ci
npx netlify-cli login
npx netlify-cli link
npx netlify-cli deploy --build --prod
```

На шаге link выбери существующий проект Netlify. Следующие обновления можно выкладывать последней командой.

## Музыка

В полной сборке используются облегченные MP3, около 16 МБ суммарно. Архив обновления лидерборда их не дублирует. Скачанный трек повторно используется из памяти текущей страницы. Музыкальный кеш не записывается приложением в постоянное хранилище; при закрытии страницы освобождается. Последнее имя и локальный рекорд сохраняются отдельно.

## Проверки

npm test — проверки правил топ-10, сохранения, повторных запросов, конкурентного обновления результата, истекших заездов и показа формы имени. Живое хранилище и телефон проверяются после деплоя по шагу 5.

## Обновить существующий репозиторий через браузер

1. Распакуй архив обновления. Внутри папки dist, server, tests и файл README-NETLIFY.md.
2. Открой корень своего репозитория GitHub (там, где netlify.toml). Выбери Add file → Upload files.
3. Перетащи содержимое распакованного архива, сохраняя папки dist, server и tests. Сам ZIP и внешнюю папку-обертку загружать не нужно. Совпадающие пути обновят существующие файлы; новый шрифт добавится. Удалять старые файлы не нужно.
4. Внизу введи сообщение Arcade leaderboard update, выбери Commit directly to main (или твою ветку production) и нажми Commit changes.
5. Если Netlify подключен к этой ветке, он автоматически начнет новый деплой. Дождись Published в Deploys, затем обнови страницу игры.

Архив обновления не содержит музыку: она не изменилась и остается в репозитории. Таблица Netlify Blobs также остается на месте.
